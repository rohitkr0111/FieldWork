# Administrator guide

1. Sign into the separate CMS domain with your invited/provisioned account and current authenticator code.
2. Add or review industries and categories, then create the client record.
3. Upload optimized screenshots through the signed Cloudinary flow; add meaningful alt text. Do not upload source code or credentials.
4. Create a project with a unique URL slug, live HTTPS URL, descriptions, client, industry/category, thumbnail, gallery, features and tags. New records are drafts. Review the live link and metadata before publishing.
5. Review testimonials and approve only client-authorized, genuine submissions. The platform does not seed sample testimonials.
6. Work enquiries through New, Contacted, Qualified, Proposal Sent, Converted, Not Interested or Closed. Keep internal notes factual and minimal.
7. Assign roles using least privilege. Revoke sessions and remove access promptly when team membership changes.

Media currently exposes signed upload and protected deletion endpoints. The CMS media index is available, while a polished drag-and-drop upload/gallery editor and full role-permission matrix editor remain deployment-level follow-up work.
